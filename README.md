# Dewey-Digital
Digitized human/machine interface for the storage and access of human knowledge.

Concept: Using standardized Dewey decimal based classification for machine learning models, and human reference and control.

Provides a method to store data in a physical location on a specific drive, not a obscure hexadecimal address.

Linux general use system to be published, but a freeBSD version to include all features and closed source code. Free license use for public/private institutions may or may not be made available.
